# Parkinson’s Disease Detection Using Eye-Movement Analysis

## Overview

This project was conducted as part of a research collaboration between **L3S Lab at the National Engineering School of Tunis (ENIT), Tunisia, Paris Descartes Information Technology Lab, France & RAZI Hospital**. The research focused on exploring machine learning techniques for Parkinson’s disease detection through the analysis of eye-movement data.

The project investigates whether eye-movement patterns captured in MOC (eye-movement) videos can help distinguish individuals affected by Parkinson’s disease from healthy controls.

The research workflow involved three main stages: pursuit coding, feature extraction, and machine learning classification, implemented through Jupyter notebooks.

## Research Objectives

- Investigate eye-movement patterns as potential indicators of Parkinson’s disease.
- Apply pursuit coding techniques to process and represent eye-movement information.
- Extract and analyze relevant features from the processed data.
- Develop and evaluate machine learning classification models to distinguish Parkinson’s disease patients from healthy controls.
- Compare model performance to identify promising approaches for automated classification.

## Methodology

### 1. Pursuit Coding

The first stage focuses on pursuit coding to process and represent eye-movement information from the available video data. This stage prepares the data for subsequent feature extraction and quantitative analysis.

### 2. Feature Extraction

The second stage involves extracting quantitative features from the processed eye-movement data. Feature engineering aims to identify relevant characteristics and patterns that may help differentiate Parkinson’s disease patients from healthy individuals.

### 3. Classification Model

The final stage uses the extracted features to train and evaluate supervised machine learning models for binary classification:

- **Parkinson’s disease (PD):** Individuals affected by the disease.
- **Healthy controls (HC):** Individuals without the disease.

Multiple classification algorithms are evaluated and compared to assess their ability to distinguish between the two groups.

## Technologies and Methods

- **Programming language:** Python
- **Development environment:** Jupyter Notebook
- **Data processing:** Video and eye-movement data analysis
- **Feature engineering:** Quantitative feature extraction and analysis
- **Machine learning:** Supervised binary classification
- **Model evaluation:** Comparison of classification performance using appropriate metrics

## Research Significance

This project explores the application of mathematical modeling, signal analysis, and machine learning to a biomedical research problem. By analyzing eye-movement data, the research investigates the potential of data-driven methods to support Parkinson’s disease detection.

Conducted within an academic research collaboration between L3S Lab at ENIT and Descartes Lab in France, the project provided experience in experimental analysis, feature engineering, model development, and the application of machine learning to healthcare research.

The results should be interpreted within the limitations of the available dataset and experimental methodology. The developed models are research tools and are not intended to replace clinical diagnosis.
